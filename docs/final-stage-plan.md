# CookKG 最终阶段工作与三人验收

## 最终问题

CookKG 要同时回答两类问题：一是“在库存、忌口、菜数和采购上限下应选哪组道菜”，
二是“这些推荐、排除或做法为什么成立”。前者由知识图谱和集合运算给出确定性结论，
后者由 HybridCypher 检索图关系与菜谱原文，再由模型生成带引用回答。

## 冻结数据流

```text
HowToCook 固定提交 → 双人审核 → 标准图和 Evidence
用户菜单条件 → 归一化 → 类别展开 → 硬过滤 → 联合补购排序
用户自然语言问题 → 路由 → 文本召回 → 参数化图扩展 → 去重排序
                   → 编号证据 → LLM → 引用校验 → 页面
```
