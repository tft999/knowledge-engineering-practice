## 与推荐系统的兼容性核对

最新项目基线为 `ed3cf27`，已包含 `src/cookkg/api.py`、分层推荐 API 和真实菜单规划前端。
完整 v2 图谱不能直接替换严格推荐图：其中仍有 `unknown`、未审核关系、开放组和工具组。
第一阶段整合后，`data_backend.build_backend_projection` 支持封闭食材选择组，并生成边界明确的兼容图：
100 道菜全部保留可追溯节点，53 道草稿标为 `integration_eligible`；35 道因来源或标注问题、
8 道因缺少公开菜名、4 道因工具选择组被阻断。家庭资源“水”不会进入采购边。
